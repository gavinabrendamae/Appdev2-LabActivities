Permission matrix (RBAC)

In CareConnect these rules are enforced in Supabase using Row Level Security policies, e.g. is_staff(), is_clinical(), is_admin().

What this demonstrates

  • Role-Based Access Control — permissions belong to roles, not to individual people.
  • 401 Unauthorized — not logged in; the server does not know who you are (an AuthN problem).
  • 403 Forbidden — logged in, but your role is not allowed (an AuthZ problem).
  • Ownership — a resident may read only their own record, never another resident’s.
  • Least privilege — each role gets only what it needs.
